OpenSSH Server
Kami memilih OpenSSH server karena ARKANODE Linux Server dirancang untuk menyediakan layanan web server dan file server yang dapat dikelolah dari jarak jauh.
Dengan OpenSSH Server, administrator dapat mengelola dan mengakses server melalui koneksi SSH tanpa harus berada lansung di depan komputer server.

Kami memilih OpenSSH dibandingkan akses jarak jauh yang tidak terenkripsi karena SSH menggunakan menggnakan enkripsi untuk melindungi komunikasi antar client dan server. 
Hal ini penting untuk menjaga keamanan proses login maupun pengelolaan server, terutama ketika administrator mengakses server melalui jaringan.

Selain itu, OpenSSH Server memudahkan administrator dalam menjalankan perinta linux, memeriksa kondisi layanan seperti 
Nginx, Samba, dan FTP, serta melakukan pemeliharaan server dari komputer lain.Paket ini sesuai dengan tujuan ARKANODE Linux Server 
karena membantu administrator mengelola layanan web server dan file server secara lebih praktis, aman, dan efisien.
