# Branding ARKANODE Linux Server

## 1. Identitas Distro
- Nama: ARKANODE Linux Server
- Kategori: Lightweight Linux Server
- Fokus: Web Server dan File Server
- Distro Induk: Ubuntu 24.04 LTS

## 2. Identitas Visual
- Warna utama: Navi Blue
- Warna Pendukung: cyan dan blue
- Logo: logo resmi ARKANODE linux server
- wallpaper: wallpaper resmi ARKANODE linux server

## 3. Tujuan Branding
Branding ARKANODE dibuat untuk memberikan identitas visual yang konsisten pada disto linux yang berfokus pada
layanan web server dan file server.

## 4. Penerapan
Logo digunakan sebagai identitas distro, sedangkan wallpaper digunakan sebagai latar belakang dekstop.
